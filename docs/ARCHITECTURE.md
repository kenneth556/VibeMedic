# VibeMedic: Architecture & Design Philosophy

`VibeMedic` is engineered as a zero-dependency, agent-agnostic framework for systematically repairing, completing, and hardening web and mobile applications generated by AI.

---

## Architectural Principles

### 1. Codebase as Ground Truth
AI models frequently hallucinate that a feature is complete when only a UI button or empty mock function exists. The prompts in this repository force the agent to traverse the full 5-tier lifecycle:
$$\text{UI Component} \longrightarrow \text{State / Handler} \longrightarrow \text{API / Service} \longrightarrow \text{Backend / DB} \longrightarrow \text{Persistence / Reload}$$

### 2. Zero-Fake Data Contract
Any application that relies on `setTimeout`, mock users, or hardcoded stats is flagged and refactored to use legitimate database queries or dynamic computation.

### 3. Non-Destructive Refactoring
Prompts mandate that existing working code and design language are preserved. Agents are prohibited from rewriting working systems or replacing libraries merely for personal preference.

### 4. Mandatory Verification Pipeline
Before an AI agent can declare any task complete, it must execute:
1. **Typecheck** (`tsc --noEmit`, etc.)
2. **Lint** (`eslint`, `biome`, etc.)
3. **Tests** (`vitest`, `jest`, `playwright`, etc.)
4. **Build** (`npm run build`, `vite build`, `next build`, etc.)
