# Prompt 32: Project Documentation Generator

> **Stage 5 — Standards & Docs**  
> **Target:** README, CONTRIBUTING, ARCHITECTURE, DEVELOPMENT, FEATURES, TROUBLESHOOTING, .env.example  
> **Output:** Accurate, Code-Derived Developer & AI Documentation Suite

---

## Prompt Text

```text
Create comprehensive documentation for this repository so that a new developer or AI coding agent can understand and modify it safely.

Inspect the actual codebase before writing documentation.

Create/update:

README.md
CONTRIBUTING.md
ARCHITECTURE.md
DEVELOPMENT.md
FEATURES.md
TROUBLESHOOTING.md
.env.example

Document:

- What the application does
- Tech stack
- Project structure
- Architecture
- Installation
- Environment variables
- Database setup
- Authentication setup
- Running locally
- Testing
- Linting
- Type checking
- Building
- Deployment
- Major features
- API structure
- Database structure
- Important conventions
- Common failure points
- Known limitations
- External services
- Development workflow

Most importantly, make the documentation reflect the ACTUAL CODEBASE.

Do not invent features.

Do not claim functionality exists if it does not.

Keep documentation concise enough for an AI coding agent to consume efficiently.
```
