# Prompt 14: Accessibility (a11y) & Semantic HTML Audit

> **Stage 2 — Repair**  
> **Target:** Keyboard navigation, focus traps, aria labels, screen readers, contrast, form labels  
> **Output:** Accessibility Conformance Report & Keyboard Navigation Fixes

---

## Prompt Text

```text
Perform a complete accessibility audit of the application.

Inspect:

- Semantic HTML
- Keyboard navigation
- Focus management
- Forms
- Labels
- Buttons
- Links
- Modals
- Dialogs
- Dropdowns
- Tabs
- Tables
- Images
- Icons
- Tooltips
- Error messages
- Loading states
- Screen-reader behavior
- Color contrast
- Disabled states

Find accessibility problems that could prevent users from operating the application.

Fix safe issues while preserving the existing visual design.

Ensure interactive elements are usable without a mouse where appropriate.

Do not replace the application's design system unnecessarily.

Run the normal verification suite afterward.
```
