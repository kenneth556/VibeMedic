# Prompt 16: Responsive & Multi-Device Design Audit

> **Stage 2 — Repair**  
> **Target:** Breakpoints, overflows, mobile navigation, touch targets, horizontal scroll  
> **Output:** Multi-Viewport Responsiveness Fixes (Desktop, Laptop, Tablet, Mobile)

---

## Prompt Text

```text
Perform a complete responsive design audit.

Inspect every page and major component across:

- Desktop
- Laptop
- Tablet
- Mobile

Find:

- Overflow
- Broken layouts
- Unusable tables
- Buttons extending outside containers
- Text clipping
- Modal problems
- Navigation problems
- Fixed elements covering content
- Incorrect responsive breakpoints
- Images overflowing
- Forms becoming unusable
- Touch targets that are too small
- Horizontal scrolling where it should not exist

Fix responsive problems without redesigning the application.

Preserve the existing design language.

Verify that fixes do not break desktop layouts.
```
