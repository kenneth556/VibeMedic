# Prompt 25: UI/UX Design System & Layout Consistency Audit

> **Stage 4 — Experience & Polish**  
> **Target:** Typography, spacing, borders, cards, shared primitives, visual hierarchy  
> **Output:** Consistent UI Design System & Component Primitive Standardization

---

## Prompt Text

```text
Perform a COMPLETE UI/UX audit of the entire application.

Your goal is to make the interface feel like a polished, intentional, production-quality product rather than a generic AI-generated application.

Inspect EVERY page and major component.

Evaluate:

- Visual hierarchy
- Typography
- Font sizes
- Font weights
- Spacing
- Padding
- Margins
- Alignment
- Grid systems
- Layout consistency
- Card design
- Buttons
- Inputs
- Forms
- Tables
- Navigation
- Sidebars
- Headers
- Modals
- Dialogs
- Dropdowns
- Tabs
- Empty states
- Loading states
- Error states
- Success states
- Notifications
- Tooltips
- Icons
- Images
- Illustrations
- Mobile layouts
- Dark/light themes where applicable

Look for:

- Inconsistent spacing
- Random font sizes
- Inconsistent border radius
- Inconsistent shadows
- Misaligned elements
- Oversized UI
- Tiny UI
- Poor hierarchy
- Clutter
- Excessive empty space
- Visually inconsistent components
- Generic-looking cards
- Inconsistent buttons
- Inconsistent icons
- Poor form layouts
- Poor information density
- Bad mobile layouts
- Unnecessary decorative elements
- Repeated UI patterns that should use shared components

IMPORTANT:

Do not completely redesign the application.

Preserve the application's existing brand identity and visual direction.

Create consistency rather than replacing everything.

If the application already has a design system, use it.

If it does not, establish a lightweight consistent design system based on the application's existing visual language.

Create/reuse shared primitives where appropriate for:

- Button
- Input
- Select
- Card
- Modal
- Dialog
- Badge
- Tooltip
- Tabs
- Table
- Toast
- Skeleton
- Empty state

Make the UI consistent across the entire application.

Fix the most important visual problems.

Do not sacrifice usability for aesthetics.

After changes, check desktop, tablet, and mobile layouts.
```
