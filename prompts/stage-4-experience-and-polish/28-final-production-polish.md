# Prompt 28: Final Production Quality & Visual Polish Pass

> **Stage 4 — Experience & Polish**  
> **Target:** Micro-spacing, typography, alignment, state transitions, cohesive finish  
> **Output:** Elimination of "AI-Generated" Roughness & Premium Product Finish

---

## Prompt Text

```text
Perform a final production-quality polish pass across the entire application.

Do NOT add major new features.

Instead, identify the small details that make the application feel unfinished.

Check:

- Spacing
- Typography
- Alignment
- Icons
- Button states
- Hover states
- Focus states
- Disabled states
- Loading states
- Skeletons
- Empty states
- Error messages
- Success feedback
- Toasts
- Animations
- Page transitions
- Modal transitions
- Form validation
- Mobile behavior
- PWA behavior
- Accessibility
- Visual consistency

Look for:

- "AI-generated" looking UI
- Random icons
- Inconsistent terminology
- Placeholder copy
- awkward spacing
- inconsistent component styles
- abrupt state changes
- missing transitions
- visual bugs
- unfinished screens
- pages that feel less polished than the rest of the application

Fix these details while preserving the existing product identity.

Do not add visual effects just for the sake of adding visual effects.

The final result should feel intentional, cohesive, fast, accessible, and production-ready.
```
