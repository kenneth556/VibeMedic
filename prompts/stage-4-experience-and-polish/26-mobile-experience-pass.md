# Prompt 26: Mobile-First Experience & Ergonomics Pass

> **Stage 4 — Experience & Polish**  
> **Target:** Touch ergonomics, mobile drawers, safe areas, one-handed usability, virtual keyboard  
> **Output:** Dedicated Mobile UX Polish across all Primary Screens

---

## Prompt Text

```text
Perform a dedicated mobile product-quality pass.

Treat the application as if users will primarily access it from a phone.

Inspect every major flow.

Improve:

- Touch targets
- Bottom navigation where appropriate
- Mobile menus
- Mobile forms
- Keyboard behavior
- Input sizes
- Scroll behavior
- Tables
- Cards
- Modals
- Drawers
- Sticky elements
- Safe-area handling
- Orientation
- Loading states
- Offline state

Make sure important actions are reachable with one hand where practical.

Avoid desktop layouts simply shrinking into mobile.

Use appropriate mobile patterns instead.

Do not redesign the entire product unnecessarily.

Verify both mobile and desktop after changes.
```
