# Prompt 30: End-to-End User Journey & UX Flow Audit

> **Stage 4 — Experience & Polish**  
> **Target:** First-time users, returning users, empty/heavy data states, edge journeys, error recovery  
> **Output:** User Journey Map, Friction Elimination & Navigation Streamlining

---

## Prompt Text

```text
Audit the application from the perspective of an actual user.

Identify the primary user journeys.

For each journey, simulate:

FIRST VISIT
→ SIGN UP/LOGIN
→ ONBOARDING
→ MAIN ACTION
→ SUCCESS
→ RETURN VISIT

Also test:

- First-time users
- Returning users
- Users with no data
- Users with lots of data
- Users making mistakes
- Users with slow connections
- Users who lose connection
- Unauthorized users
- Expired sessions

Find:

- Confusing navigation
- Dead ends
- Missing feedback
- Unexpected redirects
- Unclear actions
- Poor error messages
- Missing confirmation
- Excessive steps
- Inconsistent terminology
- Features users cannot discover
- Important actions buried too deeply

Fix UX problems that can be safely improved.

Do not add unnecessary onboarding or popups.

Every important user journey should have a clear beginning, action flow, and completion state.
```
